# 超神机械师 · WorldBox 模组

> 基于齐佩甲同名小说《超神机械师》世界观制作的 WorldBox 0.51+ 全内容模组。
> 作者：阿鱼要吃书 | 原著：齐佩甲

---

## 模组特色

- **五系职业体系**：机械系（一人成军）、武道系（神体）、异能系（神通）、魔法系（神权）、念力系（神魂）
- **阶位系统**：F→E→D→D+→C→C+→B→B+→A→A+→S→S+→SS→X（14阶位，原著能级门槛）
- **气力统一体系**：五系共用气力能量，基因链/魔力池/精神力是修炼阶段表现形式，跨模组兼容
- **能级（欧纳）**：原著推广到全星海的底层战力公式，适配所有体系
- **知识树**：249个知识节点，五系独立知识体系+跨系兼修+知识协同，4D超立方体可视化
- **装备系统**：9级原著品质（灰→绿→蓝→淡紫→紫→粉→橙→银橙→金），词条+精炼+耐久+制造
- **圣所系统**：6大圣所（机械/武道/异能/魔法/念力/信息态），神性蜕变+复活+权限等级
- **独立UI窗口**：知识/背包/制造/排行榜/圣所 5个独立全息窗口，星海终端风格

## 快速开始

### 安装

1. 下载最新 Release 的 zip 包
2. 解压到 `WorldBox/Mods/超神机械师/` 目录
3. 启动游戏，在模组管理器中启用

### 玩法入口

| 功能 | 入口 |
|---|---|
| 召唤机械单位/异化之灾 | 神权栏（底部超神机械师Tab，4个核心神权） |
| 查看单位信息 | 点击单位 → 单位面板（阶位/体系/能级/气力） |
| 知识树 | 单位面板 → 点击"知识"行 → 独立窗口 |
| 装备背包 | 单位面板 → 点击"背包"行 → 独立窗口 |
| 制造系统 | 单位面板 → 点击"制造"行 → 独立窗口 |
| 排行榜/圣所 | 神权栏 → 对应按钮 → 独立窗口 |

## 技术信息

- **模组框架**：NeoModLoader（源码模组模式，.cs自动编译）
- **目标游戏版本**：WorldBox 0.51.x (build 717+)
- **GUID**：`SUPERMECH`
- **入口**：`SuperMech.Main`
- **代码规模**：66个C#文件，约13,700行，按功能分9个子目录
- **本地化**：`Locales/cz.json`（中文用cz，约3740条），除日志外全部文本本地化
- **存档**：统一JSON存档，按世界seed保存，覆盖33个系统

## 代码结构

```
超神机械师/
├── Main.cs                    # 入口
├── mod.json                   # 模组配置
├── default_config.json        # 默认配置
├── Code/
│   ├── Core/                  # 核心（存档/配置/反射/统一Tick/跨模组）
│   ├── Class/                 # 职业系统（五系/分支/进阶任务/天赋）
│   ├── Power/                 # 力量系统（气力/阶位/神性/维度/核心修炼）
│   ├── Knowledge/             # 知识系统（知识树/协同/融合）
│   ├── Equipment/             # 装备系统（背包/词缀/精炼/耐久/制造）
│   ├── Sanctuary/             # 圣所系统（圣所/遗物/复活）
│   ├── World/                 # 世界系统（传承/传说/命运/技能/法师塔）
│   ├── UI/                    # UI系统（5个独立窗口/单位面板/神权）
│   └── UI/Theme/              # UI主题（星海终端风格）
├── Locales/
│   └── cz.json                # 中文本地化
└── GameResources/             # UI背景图等资源
```
