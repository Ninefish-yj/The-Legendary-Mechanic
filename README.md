# 超神机械师 · WorldBox 模组

> 基于齐佩甲同名小说《超神机械师》世界观制作的 WorldBox 0.51+ 全内容模组。
> 作者：阿鱼要吃书 | 原著：齐佩甲

---

## 模组特色

- **五系职业体系**：机械系（神器）、武道系（神体）、异能系（神通）、魔法系（神权）、念力系（神魂）
- **阶位系统**：F→E→D→D+→C→C+→B→B+→A→A+→S→S+→SS→X（14阶位，原著能级门槛）
- **气力统一体系**：五系共用气力能量，基因链/魔力池/精神力是修炼阶段表现形式，跨模组兼容
- **能级（欧纳）**：原著推广到全星海的底层战力公式，适配所有体系
- **知识树**：264个知识节点，五系独立知识体系+跨系兼修+知识协同，武装/操控/能量三支五层
- **装备系统**：9级原著品质（灰→绿→蓝→淡紫→紫→粉→橙→银橙→金），词条+精炼+耐久+制造
- **圣所系统**：6大圣所独立空间视图（星图节点，不在地图放标记），神性蜕变+复活（原著五大限制）+权限等级
- **UI原生融合**：圣所空间视图+折叠单位面板+原生事件日志+卡片排行榜，知识/背包/制造/排行榜独立窗口

## 快速开始

### 安装

1. 下载最新 Release 的 zip 包
2. 解压到 `WorldBox/Mods/超神机械师/` 目录
3. 启动游戏，在模组管理器中启用

### 玩法入口

| 功能 | 入口 |
|---|---|
| 召唤机械单位/异化之灾 | 神权栏（底部超神机械师Tab，4个核心神权） |
| 查看单位信息 | 点击单位 → 单位面板（阶位/体系/能级/气力） |
| 知识树 | 单位面板 → 点击"知识"行 → 独立窗口 |
| 装备背包 | 单位面板 → 点击"背包"行 → 独立窗口 |
| 制造系统 | 单位面板 → 点击"制造"行 → 独立窗口 |
| 排行榜/圣所 | 神权栏 → 对应按钮 → 圣所空间视图/排行榜窗口 |

### 第一步：创造超能者

进入世界后，底部神权栏会出现「超神机械师」Tab，包含4个核心神权：

| 神权 | 作用 |
|---|---|
| 召唤机械单位 | 在点击位置生成机械系单位（游骑兵/机甲） |
| 异化之灾 | 在点击位置生成异化体（天灾） |
| 圣所入口 | 打开圣所空间视图（6圣所星图节点+信息态库+复活） |
| 排行榜入口 | 打开排行榜窗口（超能者欧纳/气力/阶位排名，阶位筛选） |

## 系统详解

### 阶位系统

超能者按能级（欧纳）分为14个阶位：

```
F → E → D → D+ → C → C+ → B → B+ → A → A+ → S → S+ → SS → X（超神级）
```

| 阶位 | 能级门槛（欧纳） | 说明 |
|---|---|---|
| F | 1~2 | 凡人，刚踏入超能之路 |
| E | 100 | 气力护体可防狙击子弹（ch3） |
| E+ | 600 | E级巅峰 |
| D | 800 | 独挡小型武装部队（ch237） |
| D+ | 1,600 | D级巅峰 |
| C | 2,000 | 徒手拆楼，正面对抗军队（ch476） |
| C+ | 5,000 | C级巅峰 |
| B | 8,000 | 行星级强者 |
| B+ | 15,000 | B级巅峰 |
| A | 10,000~33,000 | 天灾级，2万以上可毁灭行星地表（ch671） |
| A+ | 20,000~33,000 | A级巅峰 |
| S | 33,000 | 超A级，常态一击爆星（ch864） |
| S+ | 65,000 | S级巅峰 |
| SS | 82,600 | 巅峰超A，临界级可尝试突破超神（ch1040） |
| X | 148,800+ | 超神级，信息态永生（ch1402） |

**注意**：原著能级是非线性曲线，前期平缓→A级陡升→S级跃迁→X级无上限。A级内部差距极大（弱A和强A+完全不是一个级别）。

### 气力系统

气力是超能者的基础能量，五系共用同一套气力体系（基因链/魔力池/精神力是修炼阶段的表现形式，不是独立能量池）。

| 项目 | 说明 |
|---|---|
| 等级 | Lv1~Lv29，原著精确阈值（Lv1=10/Lv6=1000分水岭/Lv10=9000/Lv21=18万/Lv29=48万） |
| 获取 | 修炼/战斗/击杀提取 |
| 消耗 | 技能释放先耗气力，气力空→超比例耗体力→体力空→减生命 |
| 跨模组兼容 | 自动检测其他模组的能量属性（魔力/修为等），转换为气力 |

**第六级分水岭**：气力达到Lv6（1000）后解锁"气力属性强化"，属性作用更加突出。机械师磁属性可用于制造/使用机械，宛如肢体延伸，加快速度、提高质量、强化威力。气力低于某等级阈值时丧失该等级属性加成。

**Lv29总加成**：力量+12480、敏捷+13640、耐力+17200、智力+22845、神秘+13590、体力上限+27000、机械亲和度+14670%。

**能级公式**（原著ch3/ch1039/ch1203/ch1402拟合）：
```
能级 = 22 × 气力^0.67 + 身体素质 × 0.15
身体素质 = 伤害×10 + 生命×0.5 + 速度×20 + 护甲×15
```

**气力加成公式**（原著4个数据点最小二乘拟合）：
```
属性 = 0.000921 × 气力等级^4.9 × 属性系数
属性系数：力量1.000 / 敏捷1.366 / 耐力1.521 / 智力1.718 / 神秘1.085
```

### 知识系统

点击单位面板"知识"行打开独立窗口。

**知识窗口结构**：
1. **顶部**：系别切换（5个按钮）+ 潜能点显示
2. **左侧**：知识树列表（按阶位分组，点击节点查看详情）
3. **右侧**：知识详情（描述/解锁条件/奖励）+ 解锁按钮
4. **融合标签页**：知识融合配方列表，消耗经验融合图纸

**知识阶位**：基础（灰）→ 进阶（绿）→ 高端（蓝）→ 尖端（紫）→ 终极（金）

**解锁条件**：消耗潜能点 + 前置知识已解锁；跨系兼修消耗×3（智力≥20时×2）

**知识协同**：同时学习特定知识组合可激活协同效果，获得额外加成。

### 装备背包系统

点击单位面板"背包"行打开独立窗口。

**9级品质**：灰→绿→蓝→淡紫→紫→粉→橙→银橙→金

**装备获取**：击杀掉落 / 机械系制造 / 装备融合

**装备词条**：每件装备有随机词条（伤害/生命/攻速/气力等）
**精炼系统**：消耗材料提升装备气力加成
**耐久系统**：装备有耐久度，战斗中消耗，耐久归零装备损坏

### 机械造兵系统

机械系专属玩法，点击单位面板"制造"行打开独立窗口。

**造兵流程**：选择配方 → 确认材料消耗 → 所在城市有足够资源即可制造 → 机械单位归主人控制

**造兵收益**：机械单位击杀敌人时，主人获得经验分成。

### 圣所系统

六大圣所是独立于宇宙的信息态维度空间，不在地图上显示。点击神权栏"圣所"按钮进入圣所空间视图（原著ch1266还原：白茫茫无边无际空间+无数白色光球）：

**两层结构**：
1. **圣所选择层**：6个圣所入口卡片，玩家可直接进入任何一个（上帝视角无需解锁）
2. **圣所内部层**：白茫茫背景+12~20个随机白色光球飘浮，每个光球=一个迭代文明的信息态集合体，点击查看文明记录（名称/领域/迭代/成就/毁灭原因），光门通道返回

| 圣所 | 知识方向 |
|---|---|
| 第一圣所 | 机械系技术 |
| 第二圣所 | 能量系 |
| 第三圣所 | 生物/基因/异能 |
| 第四圣所 | 时空系 |
| 第五圣所 | 维度系 |
| 第六圣所 | 信息态技术 |

**单位访问**：A级及以上自动访问匹配体系的圣所，S级+3钥匙可进入修炼。玩家是观察者，单位是参与者。

**圣所复活五大限制**（原著ch1214）：
1. **门槛**：只有超A级（S阶）及以上才能复苏
2. **人格悖论**：复苏的是否为原个体，一直是争论主题
3. **随机失能**：生前越强复苏越完整，复苏次数越多信息丢失越严重
4. **唯一存在性**：宇宙中只能同时存在一个你，未死亡时复苏无效（按原单位内部ID检查）
5. **跨迭代限制**：无法跨越迭代复苏

复活复用原单位内部ID，所有以ID为key的字典数据（气力/知识/神性/遗力等）自动关联。圣所外物品不会被复活（信息态只记录生命体信息）。

**圣所钥匙**：每圣所有不同钥匙（原始异能体+圣光粒子+混沌秘能），进入圣所只有零次和无数次。

### 超神遗力

临界超A（SS级+神性觉醒+进阶任务完成）尝试突破超神级失败时，生命精华/灵魂意识/核心能量凝聚成超神遗力。

**5种死因→4种负荷类型**：宇宙同化/基因崩溃/细胞独立/无限增殖/其他。继承者吸收遗力需承担死者死亡同等伤害（继承债务），扛不住有概率被反噬死亡。

**残存意识体**：遗力中包含死者残存意识，有名字和遗愿，继承成功后意识体消亡。

### 概念永生（资讯唯一·概念永生）

超神级（X阶）专属专长（原著ch1402）：只要全宇宙还有信息载体记录着你的事迹，只要还有人念诵他的名，就不会彻底死亡。

**机制**：超神级普通死亡时自动触发概念重塑恢复满血 → 进入180秒信息态稳定期 → 稳定期内再次死亡则真正死亡。

**反制**：信息态抹杀（超神级独有，5%概率触发），被抹杀则无法概念重塑。

圣所复活对X阶无效（超神级信息态超出圣所记录范围）。

### 信息态系统

超A级死亡时生成29字段完整信息态快照（名字/职业/分支/阶位/气力/潜能/知识/神性/遗力/进阶任务/技能/圣所权限/特质/复活次数等），存储于圣所信息态库中，可在圣所空间视图查看。

### 神性蜕变与超神突破

**神性蜕变**：气力Lv21 + 能级78000欧纳触发，职业/种族双路线，各最多10层，每层提升属性并获得圣所权限碎片。

**超神突破**（SS阶巅峰）：三条件——稳定生命形态（持有宇宙宝物）+ 四个非同系助手（都开启神性蜕变）+ 超神遗力催化剂。失败会死亡化为超神遗力，成功后成为超神级信息态永生。

## 常见问题

**Q: 为什么单位面板什么都没有？**
A: 普通人（未觉醒）没有超神机械师的信息。先用神权召唤超能者，或等待单位自然觉醒。

**Q: 知识窗口打开是空白？**
A: 知识窗口只显示当前选中系别的知识。先在顶部系别切换按钮选择一个系。

**Q: 怎么获得潜能点？**
A: 升级/进阶任务/战斗/神性蜕变都会获得潜能点。

**Q: 装备怎么穿？**
A: 背包窗口中点击物品即可装备/卸下。

**Q: 怎么制造机械单位？**
A: 机械系单位点击面板"制造"行打开制造窗口，选择配方，需要所在城市有足够资源。

**Q: 和其他模组冲突吗？**
A: 气力系统已做跨模组兼容，会自动检测其他模组的能量属性（魔力/修为等）并转换为气力。自定义属性显示在单位面板概览区域。

**Q: 超神级死了怎么办？**
A: 超神级（X阶）拥有【资讯唯一·概念永生】专长，普通死亡会自动重塑恢复满血，进入180秒稳定期。稳定期内再次死亡则真正死亡。被其他超神级用"信息态抹杀"（5%概率）也会真正死亡。

**Q: 超神遗力怎么获得？**
A: 临界超A（SS级+神性觉醒+进阶任务完成）突破超神级失败时会生成遗力。其他单位可吸收遗力获得力量，但需承担死者死亡同等伤害（继承债务），扛不住会被反噬死亡。
