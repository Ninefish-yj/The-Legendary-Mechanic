# 超神机械师 · WorldBox 模组

> 基于齐佩甲同名小说《超神机械师》世界观制作的 WorldBox 0.51+ 全内容模组。
> 作者：阿鱼要吃书 | 原著：齐佩甲

---

## 模组特色

- **五系职业体系**：机械系（一人成军）、武道系（神体）、异能系（神通）、魔法系（神权）、念力系（神魂）
- **阶位系统**：F→E→D→D+→C→C+→B→B+→A→A+→S→S+→SS→X（14阶位，原著能级门槛）
- **气力统一体系**：五系共用气力能量，基因链/魔力池/精神力是修炼阶段表现形式，跨模组兼容
- **能级（欧纳）**：原著推广到全星海的底层战力公式，适配所有体系
- **知识树**：249个知识节点，五系独立知识体系+跨系兼修+知识协同，4D超立方体可视化
- **装备系统**：9级原著品质（灰→绿→蓝→淡紫→紫→粉→橙→银橙→金），词条+精炼+耐久+制造
- **圣所系统**：6大圣所（机械/武道/异能/魔法/念力/信息态），神性蜕变+复活+权限等级
- **独立UI窗口**：知识/背包/制造/排行榜/圣所 5个独立全息窗口，星海终端风格

## 快速开始

### 安装

1. 下载最新 Release 的 zip 包
2. 解压到 `WorldBox/Mods/超神机械师/` 目录
3. 启动游戏，在模组管理器中启用

### 玩法入口

| 功能 | 入口 |
|---|---|
| 召唤机械单位/异化之灾 | 神权栏（底部超神机械师Tab，4个核心神权） |
| 查看单位信息 | 点击单位 → 单位面板（阶位/体系/能级/气力） |
| 知识树 | 单位面板 → 点击"知识"行 → 独立窗口 |
| 装备背包 | 单位面板 → 点击"背包"行 → 独立窗口 |
| 制造系统 | 单位面板 → 点击"制造"行 → 独立窗口 |
| 排行榜/圣所 | 神权栏 → 对应按钮 → 独立窗口 |

### 第一步：创造超能者

进入世界后，底部神权栏会出现「超神机械师」Tab，包含4个核心神权：

| 神权 | 作用 |
|---|---|
| 召唤机械单位 | 在点击位置生成机械系单位（游骑兵/机甲） |
| 异化之灾 | 在点击位置生成异化体（天灾） |
| 圣所入口 | 打开圣所窗口（查看6圣所解锁进度与碎片） |
| 排行榜入口 | 打开排行榜窗口（超能者欧纳/气力/阶位前20名） |

## 系统详解

### 阶位系统

超能者按能级（欧纳）分为14个阶位：

```
F → E → D → D+ → C → C+ → B → B+ → A → A+ → S → S+ → SS → X（超神级）
```

| 阶位 | 能级门槛（欧纳） | 说明 |
|---|---|---|
| F | 0 | 刚踏入超能之路 |
| E | 100 | 星海人刚觉醒的阶位 |
| D | 500 | 初级超能者 |
| C | 2,000 | 星球探索战士基础标准 |
| B | 10,000 | 行星级强者 |
| A | 50,000 | 天灾级，能毁灭行星地表 |
| S | 200,000 | 超A级，宇宙顶级强者 |
| SS | 1,000,000 | 巅峰超A，可尝试突破超神 |
| X | 5,000,000 | 超神级，信息态永生 |

**注意**：没有阶位的是普通人，F阶及以上都是超能者。

### 五系职业

| 体系 | 本质 | 特色 |
|---|---|---|
| 机械系 | 神器 | 制造装备/机械军团，一人成军 |
| 武道系 | 神体 | 体魄强化，近战格斗 |
| 异能系 | 神通 | 天生异能，基因链修炼 |
| 魔法系 | 神权 | 魔力施法，法术学习 |
| 念力系 | 神魂 | 精神力，心灵感应/预知 |

**机械系14阶段**（原著完整链）：
入门者 → 学徒 → 见习 → 磁环 → 数据 → 战争 → 虚拟 → 星海 → 真理 → 使徒 → 帝皇 → 主宰 → 神座 → 超神

### 气力系统

气力是超能者的基础能量，五系共用同一套气力体系（基因链/魔力池/精神力是修炼阶段的表现形式，不是独立能量池）。

| 项目 | 说明 |
|---|---|
| 等级 | Lv1-40，有明确阈值表 |
| 获取 | 修炼/战斗/击杀提取 |
| 消耗 | 技能释放先耗气力，气力空→超比例耗体力→体力空→减生命 |
| 跨模组兼容 | 自动检测其他模组的能量属性（魔力/修为等），转换为气力 |

**能级公式**：`能级 = 气力 × 身体素质系数 × 配置倍率`
身体素质系数 = `1 + (伤害 + 生命/10 + 速度/2) / 100`，范围1.0~2.5

### 知识系统

点击单位面板"知识"行打开独立窗口。

**知识窗口结构**：
1. **顶部**：系别切换（5个按钮）+ 潜能点显示
2. **左侧**：知识树列表（按阶位分组，点击节点查看详情）
3. **右侧**：知识详情（描述/解锁条件/奖励）+ 解锁按钮
4. **3D图谱**：4D超立方体可视化，已解锁节点发光，可拖拽旋转

**知识阶位**：基础（灰）→ 进阶（绿）→ 高端（蓝）→ 尖端（紫）→ 终极（金）

**解锁条件**：消耗潜能点 + 前置知识已解锁；跨系兼修消耗×3（智力≥20时×2）

**知识协同**：同时学习特定知识组合可激活协同效果，获得额外加成。

### 装备背包系统

点击单位面板"背包"行打开独立窗口。

**9级品质**：灰→绿→蓝→淡紫→紫→粉→橙→银橙→金

**装备获取**：击杀掉落 / 机械系制造 / 装备融合

**装备词条**：每件装备有随机词条（伤害/生命/攻速/气力等）
**精炼系统**：消耗材料提升装备气力加成
**耐久系统**：装备有耐久度，战斗中消耗，耐久归零装备损坏

### 机械造兵系统

机械系专属玩法，点击单位面板"制造"行打开独立窗口。

**造兵流程**：选择配方 → 确认材料消耗 → 所在城市有足够资源即可制造 → 机械单位归主人控制

**造兵收益**：机械单位击杀敌人时，主人获得经验分成。

### 圣所系统

六大圣所是跨存档的知识传承系统，点击神权栏"圣所"按钮打开窗口：

| 圣所 | 知识方向 |
|---|---|
| 第一圣所 | 机械系 |
| 第二圣所 | 武道系 |
| 第三圣所 | 异能系 |
| 第四圣所 | 魔法系 |
| 第五圣所 | 念力系 |
| 第六圣所 | 信息态技术 |

**复苏机制**：S阶以上单位死亡后可通过圣所复苏，消耗钥匙碎片，复苏后属性削弱（每次+10%，最多50%），超神级（X阶）信息态自动重生。

### 神性蜕变与超神突破

**神性蜕变**：气力Lv21 + 能级78000欧纳触发，职业/种族双路线，各最多10层，每层提升属性并获得圣所权限碎片。

**超神突破**（SS阶巅峰）：三条件——稳定生命形态（持有宇宙宝物）+ 四个非同系助手（都开启神性蜕变）+ 超神遗力催化剂。失败会死亡化为超神遗力，成功后成为超神级信息态永生。

## 常见问题

**Q: 为什么单位面板什么都没有？**
A: 普通人（未觉醒）没有超神机械师的信息。先用神权召唤超能者，或等待单位自然觉醒。

**Q: 知识窗口打开是空白？**
A: 知识窗口只显示当前选中系别的知识。先在顶部系别切换按钮选择一个系。

**Q: 怎么获得潜能点？**
A: 升级/进阶任务/战斗/神性蜕变都会获得潜能点。

**Q: 装备怎么穿？**
A: 背包窗口中点击物品即可装备/卸下。

**Q: 怎么制造机械单位？**
A: 机械系单位点击面板"制造"行打开制造窗口，选择配方，需要所在城市有足够资源。

**Q: 和其他模组冲突吗？**
A: 气力系统已做跨模组兼容，会自动检测其他模组的能量属性（魔力/修为等）并转换为气力。自定义属性显示在单位面板概览区域。

## 技术信息

- **模组框架**：NeoModLoader（源码模组模式，.cs自动编译）
- **目标游戏版本**：WorldBox 0.51.x (build 717+)
- **GUID**：`SUPERMECH`
- **入口**：`SuperMech.Main`
- **代码规模**：66个C#文件，约13,700行，按功能分9个子目录
- **本地化**：`Locales/cz.json`（中文用cz，约3740条），除日志外全部文本本地化
- **存档**：统一JSON存档，按世界seed保存，覆盖33个系统

```
超神机械师/
```
