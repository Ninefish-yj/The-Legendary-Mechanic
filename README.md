# 超神机械师 · WorldBox 模组

> 基于齐佩甲同名小说《超神机械师》世界观制作的 WorldBox 0.51+ 全内容模组。
> 作者：阿鱼要吃书 | 原著：齐佩甲

---

## 模组特色

- **五系职业体系**：机械系（一人成军）、武道系、异能系、魔法系、念力系
- **阶位系统**：F→E→D→C→B→A→S→SS→X（超神级），原著能级门槛
- **气力系统**：Lv1-40，决定能级与位阶，各系气力属性不同
- **机械军团**：9种造兵配方，从游骑兵到使徒兵器，一人成军
- **降临者系统**：玩家单位走等级职业体系，星海人走阶位修炼
- **圣所轮回**：6大圣所，跨存档知识传承与复苏机制
- **知识树**：249个知识节点，五系独立知识体系+跨系兼修
- **装备系统**：9级原著品质（灰→金），词条+掉落+制造

## 快速开始

### 安装

1. 下载最新 Release 的 zip 包
2. 解压到 `WorldBox/Mods/超神机械师/` 目录
3. 启动游戏，在模组管理器中启用

### 玩法入口

| 功能 | 入口 |
|---|---|
| 召唤单位/天灾 | 神权栏（底部超神机械师Tab） |
| 查看单位信息 | 点击单位 → 单位面板 |
| 知识树/装备背包 | 单位面板 → 知识Tab / 背包Tab |
| 六圣所/排行榜 | 神权栏 → 开窗按钮 |
