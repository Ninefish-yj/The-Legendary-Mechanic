## 0. 一页摘要

**一句话**：把"星海宇宙"压缩到一个 WorldBox 世界——文明从星球时代走向星际时代，经历 1.0→5.0 五个版本浩劫，核心体验是**机械文明的"一人成军"、玩家（异人）的降临与收编、版本大事件的改写世界**。

**与同级模组的差异**（诡秘之主=序列+信仰、启源修仙=修仙境界、天人武道=武道境界、现代战争=现代兵种）：

| 模组 | 核心系统 | 我们不做 |
|---|---|---|
| 诡秘之主-宿命之环 | 22序列成神之路、教会/信仰/战争 | 不复制序列晋升与信仰网络 |
| 启源修仙 | 修炼境界、宗门、法宝、ECS架构 | 不用重型ECS（保持轻量） |
| 现代战争 | 现代武器/兵种/太空 | 不做写实现代战争 |
| **超神机械师（我们）** | **机械军团制造 + 降临者玩家 + 版本浩劫链** | —— |

## 1. 小说核心设定提炼（已核对原文）

### 1.1 力量体系（本模组的成长骨架）

- **阶位**：F（凡人）→ E → D → C → B → **A（天灾级，分水岭）** → S（超A级，分 S/S+/SS）→ **X（超神级）**；每级分下位/上位。
- **能级**：统一战斗力单位"欧纳"（E级约100欧纳起，函数式曲线增长）——映射为隐藏数值。
- **五大超能系**（主职业，需"职业知识书"就职）：异能系（基因树）、武道系（御气技巧树）、**机械系（机械知识树）**、魔法系（魔法知识树）、念力系（精神修炼树）。
- **副职业**：平民、特工、黑夜潜行者、赏金猎人等（无需知识书）。
- **七项属性**：力量/敏捷/耐力/智力/神秘/魅力/幸运；**气力**为能量核心（Lv1=10、Lv2=50、Lv3=100……）。
- **潜能点**：学职业知识/升级知识等级的唯一货币（升级、高级任务、技能满级获得）。
- **机械系专属**：知识树分**武装/能量/操控**三支、各20项知识、分基础→进阶→高端→尖端→终极五层；制造获得经验（组装/强化）；**机械系前期弱、需要巨额资金，后期一人成军**。
- **机械系进阶链**（14级）：机械入门者→机械师学徒→见习机械师→磁环机械师→数据机械师→战争机械师→虚拟机械师→星海机械师→真理机械师→使徒机械师→帝皇机械师→主宰机械师→神座机械师→**超神机械师**（转神座得"机械神明"，超神终态：武装系=宇宙帝皇、能量系=起源神君、虚拟系=至高天尊）。
- **机械造物**：机甲（星辰机甲）、战舰、炮台、机器人大军、幽能炮、随身仓库（高密物质压缩技术）；图纸品质灰/白/绿/蓝/紫/金。
- **其他体系速览**：异能=基因链随机觉醒（潜力EDCBAS评定）；魔法=专精法师/魔网法师（契约借法）；念力=精神力体系、前期克机械；武道=御气+流派武技。

### 1.2 世界与势力

- **地理**：海蓝星（新手星球，近似地球）→ 破碎星环 → 中央星海；三大文明：**光辉联邦、赤色帝国、虚灵教派**；另有银色革命军、超能灾祸、闪耀世界、世界之树、圣所。
- **海蓝星主线**：萌芽组织（瓦尔基里实验，主角韩萧=零号试验体）→ 星龙（十三局）→ 黑幽灵→黑星；**黑星军团**（黑星佣兵团→黑星军团，第337-340章起源；1.0末黑幽灵时期）。
- **宇宙级对手**：异虫（赤潮）、异神、堕落者方舟、无限财团（索罗金）、**世界树文明**（祖/镇/定/秘/新五大树王）。
- **种族**：碳基人类（黄）、兽人（苏尼尔）、龙族（龙坦浮岛·艾默丝）、械国（麦尼逊）、虚空潜影者、银灵人、异虫、半机械改造体等。

### 1.3 核心叙事机制（本模组的玩法来源）

1. **版本更新**：1.0 降临者（688公测·海蓝星）→ 2.0 异化之灾（黑星军团崛起）→ 3.0 赤潮（704·赤色帝国扩张+秘密战争）→ 4.0 闪耀世界（跨星域世界服）→ 5.0 黑星时代（圣所复苏·超能阶级冲突）→ 5.5 黑星时代·全境战争（世界树入侵终局）→ 6.0+ 轮回纪元。
2. **玩家=异人**：版本更新时"上线"，群体降生；发布任务、好感度、传授技能、收编玩家是主角的核心优势；玩家既是天灾也是天兵。
3. **影响力/传说度**：阵营好感（影响力）与个人名声（传说度）决定势力资源与招募能力。
4. **一人成军**：机械师把工厂/图纸/机械大军藏在随身仓库，个人=军团。

### 2.1 关键技术事实（已核实本机）

- 加载器：**NeoModLoader.dll**（`worldbox_Data\StreamingAssets\mods\`）；公开化游戏程序集 **Assembly-CSharp-Publicized.dll** 与 **0Harmony.dll** 在 `NML\Assemblies\`。
- 编译：启动时用 Roslyn 编译模组源码 → `NML\CompiledMods\<GUID>.dll`（已存在 XULIE.dll、CULTIWAY.dll、TIANREN_MARTIAL_WAY.dll 等，与各模组 GUID 对应）；`mod.json` 编译后变 `mod.json.close`。
- mod.json 字段：`name/author/version/description/iconPath/targetGameBuild/GUID/RepoUrl`（诡秘之主 targetGameBuild=115，需与本机一致）。
- 配置：`default_config.json`（SLIDER/SWITCH 等类型 + `Callback:"类名:方法名"`）→ 模组设置窗口。
- 本地化：`Locales/*.csv`（首行 `key,cz`）或 `Locales/cz.json`；key 前缀用 GUID 风格命名空间。

### 4.8 圣所系统（信息态遗产 · 晚期核心内容）

> 原著依据（已按结局章节订正）：**圣所不是诸星联的遗产**——圣所是超越迭代的高维存在，留言板记录历代文明（一号迭代诸星联、二号迭代三大文明、三号迭代当前宇宙，第1462/1464章）；诸星联只是试图把"守护者"绑定在不灭的圣所上，失败后成为次级维度循环时空的幻影世界（第1211章）。三大文明继承其计划改良为"信息态剥离计划"，利用圣所"每次宇宙重启添加新规律"的机制形成暗面宇宙的"小重启/暗面迭代"。圣所权限共 15 级，刷权限解锁留言与时间流速趋同（1:1）。

- **出现**：圣所作为**元持久层**从世界开局就存在（跨存档），4.0 闪耀世界（约 500 年）时以"圣所"中立遗迹势力形态现世（高科技建筑群 + 远古守卫），世界广播"圣所复苏——前宇宙文明的遗产觉醒了"。
- **形态**：中立超级城邦——不扩张、不建国、不生育；直属圣所哨兵（高属性）、信息态构造体（高维单位，克制常规机械）、圣所守护者（BOSS）；免疫版本灾难；每轮回强度提升（圣所也在"迭代"）。**权限系统**：圣所权限 15 级，随"影响力+圣所贡献"提升，逐级解锁更多支持、情报与留言板内容（还原原著刷权限解锁机制）。
- **支持机制（以一敌五获圣所支持）**：圣所观察各文明影响力/传说度/机械科技，每 N 年资助当前最强者：解锁**圣所科技**（信息态护盾、高维投射、圣所图纸=机械知识树尖端/终极层唯一来源）、派遣圣所卫队加入该文明。
- **争夺机制**：其他文明可宣战圣所——击败守卫获得**圣所控制权**（巨额加成 + 圣所科技独占）；但控制者会被三大文明联合制裁（原著"三大文明联手制裁超A级协会"）→ 触发"圣所之争"战争事件；圣所被毁则世界永久失去信息态来源（高风险高收益）。
- **轮回联动（圣所=轮回钥匙）**：轮回即原著"暗面迭代·小重启"——圣所每次宇宙重启都会添加新规律（第1464章），本模组的轮回触发、新内容解锁全部由圣所机制驱动；轮回2「真实宇宙」由圣所打开信息态通道；圣所存在时轮回奖励更高，被毁则轮回降级/暂停（可配置）。
- **慰灵碑联动**：战死超A级进入慰灵碑榜，圣所复苏时按榜复活（原著：慰灵碑=复苏名单/战绩榜，第1384/1462章）。
- **剧情闭环**：圣所面板显示"轮回记录"（**跨存档累积**），随轮回逐轮揭示终极秘密（一号诸星联→二号三大文明→三号当前宇宙、暗面迭代）。
- **跨存档机制（圣所=元持久层）**：圣所数据存独立 mod 存档（跨世界共享）——每局结束/轮回时，圣所留言板写入该世界的"轮回记录"；新世界开局圣所仍存在，留言板带着前一个世界的遗产（对应原著：三大文明发现圣所、了解历代迭代情报）。圣所权限跨档累积，玩得越多解锁的终极秘密越多——这是本模组独有的"跨存档遗产"玩法。

### 4.9 本地化与 UI

- `Locales/`：general/traits/powers/events/buildings/units.csv，全中文，key 前缀 `supermech.`。
- 自定义 UI：黑星面板（版本进度、影响力/传说度排行、事件日志）、机械知识树窗口（武装/能量/操控三支）、圣所面板（轮回记录/圣所状态/终极秘密解锁进度）。

## 5. 独有特殊玩法（三轴系统，逐条设计）

### 轴1｜机械军团：一人成军（核心中的核心）

- 王国获得"机械师文化/黑星角色"后解锁**机械工厂**。工厂消耗**金属资源 + 能量**，按队列产出：无人机→游骑兵机器人→炮台（驻守）→机甲→装甲军团。
- 机械单位**不消耗粮食、不生育、不怕饥饿**，但每秒消耗能量；能量由能量核心产出，**能级科技决定机械单位数量上限**（F=0、E=10、D=30、C=80、B=200、A=500、S=1200、X=3000，可配置）。
- 机械师角色通过"制造行为"积累经验提升**机械知识树**（武装/能量/操控），解锁更高阶单位与"强化改装"（给机械单位加装伤害/护甲/射程）。
- **次级维度行军**（原著帝皇机械师招牌技能，第762/846章）：高阶机械师可把整个机械军团收进随身次级维度、战斗时开门瞬间投放——对应"军团数量上限突破 + 空间传送投放"，是"一人成军"的原版机制；模组中由帝皇机械师以上阶位解锁。
- **还原细节**：械力=机械系气力（磁环转职起称械力，第237章）；高阶技能名直接复用原文（万物模拟/维度工厂/机械火种增殖/机械文明强化/使徒进化/合体·机械神明，第958章；超神三终态=机械神灵·至高天尊/宇宙帝皇/起源神君，第1403章）；压缩球=饰品化随身携带（第419章）。
- 表现：一个"人口萎缩但机械大军膨胀"的文明——这就是黑星军团。
- **上帝侧乐趣**：观察机械洪流推平地图 / 手动召唤机械军团投放。

### 轴2｜降临者：玩家即天灾，玩家即天兵

- **版本更新触发"玩家降临"**：一次性在随机位置降生 100~500 名"异人"（随机中文名如"狂刀怒剑""小广告代练"），属性 2~5 倍于原住民，性格多样（会建城、会结盟、会掠夺、会自相残杀）。
- **影响力/好感度系统**：每个王国维护"影响力"数值（消灭敌人/完成目标/传奇单位存在提升）。玩家单位倾向加入**影响力最高的王国**（黑星军团的招募优势=原著"发布任务"）。
- **黑星任务机制**：拥有黑星角色的王国可对玩家单位"发布任务"（领地内的临时雇佣兵：限时加入、战斗狂热）。
- 玩家单位会"独立建国"（玩家王国），形成新的势力平衡。

### 轴3｜版本浩劫：会"更新"的世界

世界按年份推进版本（时间轴见第6节），每版本=一场全图级灾难 + 新内容解锁 + 世界广播（历史记录）：

## 6.1 轮回纪元设计（世界树之后 · 无尽演化）

> **设计原则：WorldBox 是永续沙盒，模组不设终点。** 5.0 世界树不是终局，而是最后一个"版本"；之后世界进入**轮回纪元**——每过 200 年触发一次"宇宙重启"，威胁与内容螺旋上升，永无止境。
> 原著依据：宇宙已历经 4 次重启、三大文明借"暗面迭代"积攒力量试图踏入真实宇宙（5.5 卷收尾设定）——天然支撑"无尽轮回"，越往后越接近小说终章格局。

### 6.1.1 世界树事件结束判定（三选一达成即判定，之后进入新纪元而非终局）

1. 击杀全部树王（祖/镇/定/秘/新）→ 世界树撤退，**新树王投靠**当前影响力最高的文明（原著桥段）；
2. 击退入侵部队至阈值并存活 N 年（默认 50 年，可配置）；
3. 出现超神级（X级）单位（黑星完成"超神机械师"转职）。

### 6.1.2 5.5 全境战争之后：圣域纪元（过渡纪元，不是结束）

- 全图停战缓冲期（战争频率大降）；
- 影响力第一的文明（或黑星军团）建立**超能圣域**：中立仲裁势力，直属传奇单位，免疫版本灾难；
- 异神残党/堕落者方舟残余小规模骚扰，保持紧张感；
- 投靠方获得世界树科技（新树王守卫单位）；
- **传承机制**：黑星隐退，传授技能给继任者（尼洛/随机传奇），传说度转移；传奇单位半神化（不自然死亡、可战死）。

### 6.1.3 轮回纪元（核心：世界不结束，周期重启）

- **节奏**：每 200 年一个轮回（可配置）。轮回触发时发生一次"宇宙重启"级变化：**新威胁浪潮 + 新内容解锁 + 世界广播**；但文明格局、圣域、传奇单位、机械科技**全部保留**。
- **原著依据（第1464章）**：轮回即原著"暗面迭代·小重启"——暗面宇宙每次小重启基于信息态模板成型、圣所每次重启添加新规律；本模组轮回事件池=每次小重启的"信息异化"产物（世界树、枢蛇等即异化产物）。
- **轮回事件池**（示例，可扩展）：

| 轮回 | 内容 |
|---|---|
| 轮回1「暗面迭代」 | 三大文明的"暗面"黑化化身入侵（暗面联邦军/帝国军/教团） |
| 轮回2「真实宇宙」 | 圣所打开信息态通道，真实宇宙实体渗入（高维单位，克制常规机械） |
| 轮回3「圣所深层」 | 圣所完全苏醒：深层遗迹守卫激活，终极知识/圣所科技全面解锁 |
| 轮回4「异神再临」 | 异神残魂聚合体卷土重来 |
| 轮回5+「机械神明战争」 | 神座机械师互战时代：超神单位成为常态，全图大混战 |

- **难度螺旋**：每轮回敌人强度 +20%（可配置），并解锁新宝物/新科技层，世界越打越热闹。
- **玩家（上帝）选择**：每次轮回触发前二选一——**开启下一轮回**（挑战升级）或 **停留当前纪元**（沙盒安逸，世界照常演化，之后仍可手动开启）。

### 6.1.4 为什么这样设计

- 没有"通关/结束"概念，完全贴合 WorldBox 永续沙盒本质；
- 原著"宇宙重启 + 暗面迭代"设定无缝支撑轮回叙事；
- 与同级模组差异：诡秘之主/启源修仙/天人武道均为"内容铺完即止"，本模组的**无尽轮回 + 难度螺旋**是独有的长线玩法。

## 10. 风险与取舍

1. **性能**：机械单位与玩家单位数量是主要风险 → 全局限额 + 池化 + 分批生成。
2. **兼容性**：只用原版 API + 精确 patch；不覆盖原版资产；GUID 唯一（SUPERMECH）。
3. **美术**：前期用占位色块，后续补像素图（可参照现代战争的 GameResources 组织）。
4. **平衡**：阶位倍率与机械上限需反复调；AI 文明滚雪球问题用"能量消耗"与"版本灾难"对冲。
5. **存档**：版本进度/影响力等存独立 mod 存档，避免污染原版存档。
6. **小说还原度**：设定以"可玩"为第一优先级，剧情做氛围还原（世界广播/角色名/事件名），不做逐章复刻。

## 0. 融合总原则（三条）

1. **机制复用优先**：单位=Actor、职业=UnitClass、特性=Trait（ActorTrait/SubspeciesTrait/CultureTrait/KingdomTrait/ReligionTrait）、王国=Kingdom、事件=WorldEvent/WorldBehaviour、神权=GodPower、史册=WorldLog、世界法则=WorldLaw。凡是本体有对应物的设定，一律落本体资产，代码只做"连接逻辑"。
2. **设定做"数值与命名"，不重做玩法**：小说里的面板/阶位/技能/品质，映射为本体属性、特性、状态与名称；小说独有的高维机制（次级维度行军、圣所、轮回），用少数 Harmony patch + 自建系统实现——参照诡秘（经济/战争链条）、天人武道（基因境界/领域）、启源（ECS 资产库）、天地道途（105境/功德经济/持久层）。
3. **跨档与无限**：圣所=模组自有持久层（独立存档），世界结束→新世界继承，实现"世界盒子不设终点"（参照 LOOPBOX 的循环 + 天地道途的持久化思路，但圣所继承是跨存档元数据，不随世界重置）。

## 2. 八大核心系统的融合设计

### 2.1 力量体系 → 职业 × 特性 × 阶位（框架 4.1）

**落点**：
- **五系职业**=五棵 UnitClass 链（机械系=14级进阶链，从"机械入门者"到"超神机械师"，每级=一个职业资产，用转职任务/经验门槛串起来）。
- **阶位**=动态挂载的阶位特质（F→E→D→C→B→A→S→超A→圣体/至高级），按 B1 对照表（原文 ch476）映射属性：每档给固定"能级"加成（欧纳→WB 攻击/生命/攻速/寿命），实例：E级≈300-500欧纳≈25级、超A级≈150+级+特权。
- **专长/技能**=ActorTrait 与战斗技能：直接照搬原文实例数值（B3 抽能力5例、B7 专长例：【幸运诅咒】幸运-90%、【痛苦复仇】每失3%生命→1.5%伤害）。专长做被动特性、技能做冷却状态。
- **气力/械力/魔力**=单位状态资源：气力槽（恢复速率=气力恢复%专长），械力=机械系施法/制造资源；魔法师=法术位制（每日次数上限，参照魔网法师契约=冷却无消耗）。

**参考**：天人武道把境界做成"亚种基因+隐窍位点"，属性全靠基因觉醒——我们的**异能基因树**可直接复刻：异能者带"基因链"亚种特质，击杀/经验解锁基因位点（威力/操控/持久+新用途）。

### 2.2 机械系 → 机械军团一人成军（轴1，框架 4.2）

**落点**：
- **机械单位**：机械师可"制造"机械单位（傀儡/无人机/机甲/机械生命），机械单位=不可繁殖、随制造者同阵的 Actor；制造=神权或技能（消耗械力+伊纳尔+图纸），上限=机械亲和等级。
- **机械工厂**：特殊建筑（王国建筑，产机械单位/升级机械），参照现代战争"建筑+载具"、启源"建筑资产"。
- **次级维度行军**（帝皇招牌，ch762）：神权——在选定区域开"维度门"（特效），门内涌出当前随身军团（压缩球=随身携带的机械单位库存，UI 上表现为"随身机械库"）。
- **进化链**：机械单位可强化（橙装武器=带 modifier 的武器资产，如冰河冻星炮=大型攻城单位）。

**差异化**：WB 原版单位=生物繁殖逻辑，机械单位完全绕开繁殖/饥饿/寿命，由"制造-维护-升级"驱动，形成**机械文明 vs 生物文明**的对照，这是其他模组没有的。

### 2.3 降临者 → 玩家即天灾（轴2，框架 4.3）

**落点**：
- **降临神权**：玩家可召唤"异人"（降临者单位）：随机姓名（玩家ID风格）、升级极快、不繁殖、死亡后按"不灭者"规则重生（白光回城/回营地）。
- **玩家生态**：异人自动聚集建聚居地（大角山式）；职业联赛=周期性世界事件（异人单位按职业/战力排名，史册记录"联赛冠军"）；肉包=事件播报者（星海时报条目）。
- **第四天灾压力**：异人单位比例随时间增长，给世界带来"混乱"（类似 WB 的疯狂单位压力但更组织化）。

**参考**：现代战争 UnitSpawnWindow（召唤单位）、诡秘的非凡者生态（人口-材料-晋升闭环）。我们的降临者=**世界内自增长的天灾人口**，是 WB "单位"概念的新用法。

### 2.4 版本体系 → 世界纪元推进（框架 4.4/6.0）

**落点**：
- **版本阶段**=扩展 WorldAge（1.0降临者→2.0异化之灾→3.0赤潮→4.0闪耀世界→5.0黑星时代→5.5全境战争→6.0+），每版本=一组开放内容+新单位/特性/事件+等级上限（60→90→120→150→…→无上限）。
- **版本切换**=世界事件（类似公告：白屏读条式提示文本直接套用原文句式"【X.X版本开启！】【欢迎来到《星海》X.X版本——【版本名】！】"）；切换时触发该版本灾难链。
- **版本灾难链**（事件池按版本解锁）：异化之灾=瘟疫灾难+变异单位；赤潮=异虫入侵浪潮；闪耀世界=新大陆生成（参照现代战争太空/启源世界生成）；黑星时代=超A级回归事件（圣所复苏单位入场）；全境战争=多王国大规模战争（参照诡秘国家战争链条）。
- **星海时报**：版本/重大事件都写史册（WorldLog），玩家可回看"编年史"。

### 2.5 圣所 → 跨存档元持久层（框架 4.8）

**落点**（这是全模组最深的一层，也是"跨纯档机制"）：
- **圣所记录**：模组自有存档文件（不随世界重置）：记录阵亡的"超A级/英雄"名单（慰灵碑=史册+圣所名单）、玩家历史轮回记录、圣所权限等级（手背印记=权限UI）。
- **圣所复苏**：玩家获得圣所权限后可"献祭媒介"复苏指定阵亡英雄（复活+强化+新的传说度），媒介=特定物品/条件（圣所钥匙、进化方块等）。
- **圣所留言板**：迭代史册（跨世界的历史摘要：每一轮世界的兴衰大事记，按时间倒排——原文"时间越近从前往后排列"）。
- **圣所通道**：神权——在世界任意位置开启"圣所通道"（微缩白洞特效），进入圣所场景（特殊地图/区域）或召唤复苏单位。
- **跨档继承**：新世界开局=圣所仍在，带着前世界遗产（权限/名单/留言板）——这就是用户认可的"世界盒子不设终点"的机制核心。

**参考**：天地道途（持久化系统/Persistence）、诡秘（死亡遗产/守恒）、LOOPBOX（循环）。但我们把继承做成**圣所叙事化**的跨档层，不破坏本体世界生成。

### 2.6 势力 → 王国 × 文明 × 宗教（框架 4.3）

- **三大文明/歌朵拉/黯星**：亚种文明（CultureTrait：命名/军事/科技倾向）+ 王国模板（带专属单位池与外交倾向）；光辉=科技+传送神权、帝国=军事+毁灭之匙神权、虚灵=神秘+维度事件。
- **黑星军团**：事件链王国——触发条件（佣兵团信用120=正规门槛，原文ch340）→ 升格黑星军团（改名+制式装甲单位+总部卫星基地特殊建筑）；"黑星"本人=唯一传奇单位（不可重生，死了进慰灵碑，可被圣所复苏）。
- **超A级协会/超能圣域**：宗教型组织（ReligionTrait）+ 神权"召集超A"（让传奇单位跨势力集结）。
- **龙坦浮岛/战争领域**：中立城邦型王国（龙坦卫队=执法单位，袭警=高仇恨）。

### 2.7 宝物与神权 → GodPower 神权树（框架 4.7）

| 宝物（原文） | GodPower 设计 |
|---|---|
| 进化方块 | 晋升神权：选中目标单位→超A级晋升（+模板专长+传说度） |
| 时空琥珀 | 冻结区域：目标区域时间停止（单位定身数秒） |
| 毁灭之匙 | 帝国舰炮齐射：大范围无差别轰炸 |
| 暗影提灯 | 维度转化：区域变暗影维度（地形+单位状态变化） |
| 高维天启传送器 | 传送：选中单位群瞬移到目标点 |
| 圣所钥匙 | 圣所系统入口（复活/通道） |
| 慰灵碑 | 传说度展示+复苏名单 UI |
| 星海时报 | 史册阅读/版本广播（UI 窗口） |

神权树按版本解锁（1.0 只开放基础神权，4.0 开放高维神权，5.5 开放全境神权），形成"上帝逐渐变强"的长线。

### 2.8 无尽轮回 → 世界循环 + 难度递进（框架 6.1）

- 5.5 之后每 200 年进入"宇宙重启"：世界结束判定 → 生成下一轮回世界（新地图+新威胁+难度+20%）；
- 轮回事件池按轮次解锁：轮回1暗面迭代→2真实宇宙→3圣所呼啸→4异神再临→5+机械神明战争；
- 圣所跨档层在轮回间保留（权限/名单/留言板累积）；
- 上帝可随时停止轮回（停留安逸世界）或提前开启——**世界无终点**。

## 7. 风险与取舍

- **性能**：机械军团/降临者人口是高频更新点——参照诡秘"减少全图扫描与年度尖峰"的惰性结算原则，单位系统用事件驱动+索引缓存（天人武道 MartialActorIndex 做法）。
- **存档兼容**：圣所持久层独立存档，世界存档只挂引用，避免污染本体存档结构。
- **平衡**：超A级单位="一个打一城"的体验需实测调平（参考巅峰超A=数秒收割星球=后期上帝模式的"单位核弹"定位）。
- **美术**：机械单位/特效先用占位资产（改色复用本体单位+特效），后期补正式图（参照诡秘/启源的 actors 目录做法）。
- **深度克制**：机械14级+圣所+轮回是"三层深坑"，Phase 1 只做 5 职业觉醒+前4级进阶+机械工厂闭环，验证可玩性后再上高层内容。
