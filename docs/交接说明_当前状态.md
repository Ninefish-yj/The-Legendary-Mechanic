## 关键技术坑（已踩过，别再踩）

1. **net6.0 编译会被禁用**：`Dictionary<long,float>` 字段引用 `System.Collections 6.0`，游戏 Mono 运行时没有，模组被自动禁用。→ 用源码模组模式，NML 自己处理框架。
2. **`BaseSimObject.stats` 是 internal**：外部程序集运行时不能直接 `a.stats["..."]`，必须用反射。→ `Code/SuperMechStats.cs` 提供 `SuperMechStats.Of(Actor)` 反射访问。
3. **本地化用 cz.json 不是 zh.json**。
4. **BaseStats 不能存未注册的自定义 key**。
5. **stat key 没有 strength，用 warfare**。
6. **Actor.id 是 long**。
7. **必须从 Steam 启动**（appid=1206560），直接跑 exe 被 Steam 校验拦。
8. **游戏日志**：`C:\Users\faith\AppData\LocalLow\mkarpenko\WorldBox\Player.log`

**症状**：日志显示 `已注入 10/10 个神权按钮到创造tab`，无任何报错，但玩家在游戏里看不到任何按钮。

**已尝试的方法**：
- 方法A：`PowerButtonCreator.CreateGodPowerButton(id, sprite)` + `transform.SetParent(creationTab)` → 日志成功但不可见
- 方法B：克隆已有按钮模板（启源修仙 InsertWallButton 同款）+ 设置 godPower + 加入 `tab._power_buttons` + `findNeighbours/sortButtons/recalc` → 日志成功但不可见

**可能的原因**（未验证）：
- tab 路径可能不对：`CanvasBottom/BottomElements/BottomElementsMover/CanvasScrollView/Scroll View/Viewport/Content/Power Tabs/creation`
- 按钮可能在 ScrollView 可视区域外，需要滚动
- `_power_buttons` 是 private 字段，源码编译时 publicized 可见，但运行时真实程序集里可能访问失败（被 try-catch 吞了）
- 可能需要等玩家进入世界后再注入（OnModLoad 时 UI 还没完全就绪）
- 可能需要用 NML 的 `ModGodPowerButtonFeature` 特性系统来注册，而不是手动注入

**建议下一步**：参考启源修仙（`0.51+启源修仙-0.0.29`）的完整 UI 注入流程，它的按钮是可见的。重点看：
