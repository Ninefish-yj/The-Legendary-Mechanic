# 超神机械师模组 · 使用教程

> 面向玩家的玩法指南，介绍模组各系统的使用方法。

---

## 一、快速上手

### 1.1 安装

1. 下载模组 zip 包
2. 解压到 `WorldBox/Mods/超神机械师/`
3. 启动游戏 → 模组管理器 → 启用「超神机械师」

### 1.2 第一步：创造超能者

进入世界后，底部神权栏会出现「超神机械师」Tab，包含以下神权：

| 神权 | 作用 |
|---|---|
| 召唤降临者 | 在点击位置生成一个降临者单位（有面板，走等级职业体系） |
| 召唤机械游骑兵 | 生成机械系单位（E阶） |
| 召唤机甲单位 | 生成机械系单位（C阶） |
| 异化之灾 | 在点击位置生成异化体（天灾） |
| 神之催化 | 为SS阶以上单位施加突破催化（成功率+10%/层，最多5层） |

还有两个开窗按钮：
- **六圣所**：查看圣所解锁进度与碎片（跨存档）
- **排行榜**：超能者欧纳/气力/阶位排行榜（前20名）

### 1.3 查看单位信息

点击任意单位 → 打开单位面板 → 左侧有多个Tab：

| Tab | 内容 |
|---|---|
| 一般信息 | 单位基础属性（原版） |
| 特质 | 单位拥有的特质（原版） |
| 知识 | 知识树+3D知识图谱+详细信息 |
| 背包 | 装备背包（已装备+背包物品） |
| 心智 | 原版3D神经网络（原版） |
| 基因 | 原版基因/谱系（原版） |

## 二、核心系统详解

### 2.1 阶位系统

超能者按能级（欧纳）分为14个阶位：

```
F → E → D → D+ → C → C+ → B → B+ → A → A+ → S → S+ → SS → X（超神级）
```

| 阶位 | 能级门槛 | 说明 |
|---|---|---|
| F | 10 | 降临者初始阶位（玩家专属过渡） |
| E | 100 | 星海人刚觉醒的阶位 |
| C | 2000 | 星球探索战士基础标准 |
| A | 10000 | 天灾级，能毁灭行星地表 |
| S | 52000 | 超A级，宇宙顶级强者 |
| SS | 70000 | 巅峰超A，可尝试突破超神 |
| X | 140000 | 超神级，信息态永生 |

**注意**：没有阶位的是普通人，F阶及以上都是超能者。

### 2.2 五系职业

模组有五大体系，每个单位踏入超能后可选择主职业方向：

| 体系 | 本质 | 特色 |
|---|---|---|
| 机械系 | 神器 | 制造装备/机械军团，一人成军 |
| 武道系 | 神体 | 体魄强化，近战格斗 |
| 异能系 | 神通 | 天生异能，基因链修炼 |
| 魔法系 | 神权 | 魔力施法，法术学习 |
| 念力系 | 神魂 | 精神力，心灵感应/预知 |

**机械系三分支**（转职时选择）：
- 机械师：技术路线，制造为主
- 枪炮师：火力路线，远程输出
- 械武者：近战路线，殖装格斗

### 2.3 气力系统

气力是超能者的基础能量，决定能级与位阶。

| 项目 | 说明 |
|---|---|
| 等级 | Lv1-40，有明确阈值表（Lv1=10, Lv29=45万） |
| 获取 | 修炼/战斗/击杀提取 |
| 消耗 | 技能释放先耗气力，气力空→超比例耗体力→体力空→减生命 |
| 各系名称 | 机械系磁环后叫「械力」，魔法系叫「魔力」，念力系叫「精神力」 |

单位面板中气力显示为消耗条格式：`气力：100/100（Lv3）`

### 2.4 知识系统

知识是超能者后天学习的技能/理论，通过潜能点解锁。

**知识Tab三层结构**：
1. **顶部**：系别切换（5个图标按钮）+ 潜能点显示
2. **中间**：3D知识图谱（节点球面分布，已解锁发光，可拖拽旋转）
3. **底部**：知识库（按阶位分组，点击节点解锁）

**知识阶位**：
- 基础（灰）→ 进阶（绿）→ 高端（蓝）→ 尖端（紫）→ 终极（金）

**解锁条件**：
- 消耗潜能点（基础2点，进阶4点，高端6点...）
- 前置知识已解锁
- 跨系兼修消耗×3（智力≥20时×2）

**知识作用**：
- 提升基础属性
- 解锁职业技能
- 转职条件（如磁环→数据需要5项进阶知识）
- 提升技能威力（同系知识每+1个，技能伤害+2%）

### 2.5 装备背包系统

单位有独立的装备背包，支持9级原著品质：

| 品质 | 颜色 | 说明 |
|---|---|---|
| 普通 | 灰 | 基础装备 |
| 优秀 | 绿 | 小幅加成 |
| 精良 | 蓝 | 中等加成 |
| 稀有 | 淡紫 | 较好加成 |
| 史诗 | 紫 | 强力加成 |
| 传说 | 粉 | 顶级常规装备 |
| 神器 | 橙 | 使徒兵器级 |
| 神话 | 银橙 | 宇宙宝物级 |
| 超神 | 金 | 最高品质 |

**装备获取**：
- 击杀掉落（品质随机）
- 机械系制造（学会图纸后）
- 神权「赐予装备」（50%金装/50%宇宙宝物）

**装备词条**：每件装备有随机词条（伤害/生命/攻速/气力等）

### 2.6 机械造兵系统

机械系专属玩法，消耗城市资源制造机械单位。

**9种配方**：

| 配方 | 阶位 | 单位类型 | 材料 |
|---|---|---|---|
| 游骑兵 | T1 | 士兵 | 金属×5 |
| 侦察无人机 | T2 | 异形 | 金属×8+宝石×2 |
| 哨戒炮 | T3 | 水晶魔像 | 金属×15+石头×10 |
| 战斗机甲 | T4 | 螃蟹怪 | 金属×25+宝石×5 |
| 运载机 | T5 | 龙 | 金属×30+木材×20 |
| 战争堡垒 | T6 | 水晶魔像 | 精金×10+宝石×10 |
| 虚拟生命体 | T7 | 人类 | 金×20+宝石×15 |
| 星际巡洋舰 | T8 | 龙 | 精金×20+龙鳞×5 |
| 使徒兵器 | T10 | 螃蟹怪 | 精金×30+金×30+宝石×20 |

**造兵收益**：机械单位击杀敌人时，主人获得30%经验分成。

### 2.7 降临者系统

降临者是"有面板的玩家型单位"，与星海人（土著）的区别：

| 项目 | 降临者 | 星海人 |
|---|---|---|
| 成长方式 | 经验值→升级→进阶任务→转职 | 阶位修炼（自动晋升） |
| 初始阶位 | F阶 | E阶（刚觉醒） |
| 面板 | 完整属性/等级/经验 | 同样显示（玩家是神，能看到所有信息） |
| 知识融合 | 可随机融合知识配方 | 不可 |

**进阶任务**：降临者达到等级上限后，需要完成进阶任务才能转职：
- 任务级别随机（D/C/B/A/S），级别越高奖励越好
- 任务内容：击杀对应阶位的对手
- 完成后自动转职+获得经验/气力/潜能点奖励

### 2.8 圣所系统

六大圣所是跨存档的知识传承系统：

| 圣所 | 知识方向 |
|---|---|
| 第一圣所 | 机械系 |
| 第二圣所 | 武道系 |
| 第三圣所 | 异能系 |
| 第四圣所 | 魔法系 |
| 第五圣所 | 念力系 |
| 第六圣所 | 信息态技术 |

**圣所权限**：每个单位有独立的圣所权限等级（自定义属性），通过神性蜕变获得。权限越高，每次进入能带走的知识越多。

**复苏机制**：
- S阶以上单位死亡后，可通过圣所复苏
- 复苏消耗钥匙碎片
- 复苏后属性削弱（信息丢失，每次+10%，最多50%）
- 信息丢失过多会降阶，降到A级以下无法复苏
- 超神级（X阶）不靠圣所，信息态自动重生

### 2.9 神性蜕变

神性蜕变是高阶超能者的进阶系统，双路线：

| 路线 | 说明 |
|---|---|
| 职业蜕变 | 提升职业能力，最多10层 |
| 种族蜕变 | 提升种族能力，最多10层 |

**触发条件**：气力Lv21 + 能级78000欧纳

**收益**：每层提升属性，获得圣所权限

### 2.10 超神突破

SS阶巅峰超能者可尝试突破超神级（X阶）。

**三条件**（原著ch1396）：
1. 稳定生命形态（持有宇宙宝物）
2. 四个非同系助手（都开启神性蜕变）
3. 超神遗力催化剂

**突破风险**：
- 成功率受神之催化层数影响
- 失败会死亡，化为超神遗力（无法圣所复苏）
- 成功后成为超神级，信息态永生

## 三、常见问题

### Q: 为什么单位面板什么都没有？
A: 普通人（未觉醒）没有超神机械师的信息。先用神权召唤超能者，或等待单位自然觉醒。

### Q: 知识Tab打开是空白？
A: 知识Tab只显示当前选中系别的知识。先在顶部系别切换按钮选择一个系。

### Q: 怎么获得潜能点？
A: 升级/进阶任务/战斗/神性蜕变都会获得潜能点。

### Q: 装备怎么穿？
A: 背包Tab中点击物品即可装备/卸下。装备有槽位限制（武器/装甲/头盔/靴子/戒指/护身符）。

### Q: 降临者和星海人哪个强？
A: 没有绝对强弱。降临者前期升级快，星海人后期阶位修炼稳定。高阶位后两者趋同。

### Q: 怎么制造机械单位？
A: 机械系单位在知识Tab「◆操作」区域点击「机械造兵」按钮，需要所在城市有足够资源。

## 四、配置项

模组有31个配置项，在NML配置界面中可调整：

| 分类 | 说明 |
|---|---|
| General | 通用设置（调试模式/日志级别） |
| Awakening | 觉醒相关（自动觉醒概率/天赋分布） |
| Qi | 气力相关（修炼速度/消耗比例） |
| Promotion | 晋升相关（自动晋升上限/晋升间隔） |
| AutoFavorite | 自动收藏（收藏阈值/数量限制） |
| Sanctuary | 圣所相关（复苏消耗/权限获取） |
| Mech | 机械相关（造兵冷却/材料倍率） |
| Refinement | 提炼法相关（气力获取倍率） |
| Relic | 宇宙宝物相关（掉落率/效果强度） |
| Performance | 性能相关（tick间隔/最大单位数） |

## 五、与原版的兼容性

- 不修改原版单位/物品/特质，只添加新内容
- 原版装备系统与模组装备背包共存
- 原版特质/基因/心智Tab不受影响
- 存档兼容：禁用模组后，超神机械师的自定义数据会被忽略，原版数据保留
