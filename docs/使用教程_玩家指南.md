# 超神机械师模组 · 使用教程

> 面向玩家的玩法指南，介绍模组各系统的使用方法。

---

## 一、快速上手

### 1.1 安装

1. 下载模组 zip 包
2. 解压到 `WorldBox/Mods/超神机械师/`
3. 启动游戏 → 模组管理器 → 启用「超神机械师」

### 1.2 第一步：创造超能者

进入世界后，底部神权栏会出现「超神机械师」Tab，包含4个核心神权：

| 神权 | 作用 |
|---|---|
| 召唤机械单位 | 在点击位置生成机械系单位（游骑兵/机甲） |
| 异化之灾 | 在点击位置生成异化体（天灾） |
| 圣所入口 | 打开圣所窗口（查看6圣所解锁进度与碎片） |
| 排行榜入口 | 打开排行榜窗口（超能者欧纳/气力/阶位前20名） |

### 1.3 查看单位信息

点击任意单位 → 打开单位面板 → 概览区域显示自定义属性（气力/潜能点/神性蜕变/圣所权限/械感/魔感等）。

单位面板中有3个可点击的入口行，点击打开独立全息窗口：

| 入口 | 打开窗口 | 内容 |
|---|---|---|
| 知识 | 知识窗口 | 知识树+4D超立方体图谱+详细信息 |
| 背包 | 背包窗口 | 装备背包（已装备+背包物品+品质分类） |
| 制造 | 制造窗口 | 机械造兵配方列表+材料消耗 |

## 二、核心系统详解

### 2.1 阶位系统

超能者按能级（欧纳）分为14个阶位：

```
F → E → D → D+ → C → C+ → B → B+ → A → A+ → S → S+ → SS → X（超神级）
```

| 阶位 | 能级门槛（欧纳） | 说明 |
|---|---|---|
| F | 0 | 刚踏入超能之路 |
| E | 100 | 星海人刚觉醒的阶位 |
| D | 500 | 初级超能者 |
| D+ | 1,000 | D阶巅峰 |
| C | 2,000 | 星球探索战士基础标准 |
| C+ | 5,000 | C阶巅峰 |
| B | 10,000 | 行星级强者 |
| B+ | 25,000 | B阶巅峰 |
| A | 50,000 | 天灾级，能毁灭行星地表 |
| A+ | 100,000 | A阶巅峰 |
| S | 200,000 | 超A级，宇宙顶级强者 |
| S+ | 500,000 | S阶巅峰 |
| SS | 1,000,000 | 巅峰超A，可尝试突破超神 |
| X | 5,000,000 | 超神级，信息态永生 |

**注意**：没有阶位的是普通人，F阶及以上都是超能者。

### 2.2 五系职业

模组有五大体系，每个单位踏入超能后可选择主职业方向：

| 体系 | 本质 | 特色 |
|---|---|---|
| 机械系 | 神器 | 制造装备/机械军团，一人成军 |
| 武道系 | 神体 | 体魄强化，近战格斗 |
| 异能系 | 神通 | 天生异能，基因链修炼 |
| 魔法系 | 神权 | 魔力施法，法术学习 |
| 念力系 | 神魂 | 精神力，心灵感应/预知 |

**机械系14阶段**（原著完整链）：
入门者 → 学徒 → 见习 → 磁环 → 数据 → 战争 → 虚拟 → 星海 → 真理 → 使徒 → 帝皇 → 主宰 → 神座 → 超神

### 2.3 气力系统

气力是超能者的基础能量，五系共用同一套气力体系（基因链/魔力池/精神力是修炼阶段的表现形式，不是独立能量池）。

| 项目 | 说明 |
|---|---|
| 等级 | Lv1-40，有明确阈值表 |
| 获取 | 修炼/战斗/击杀提取 |
| 消耗 | 技能释放先耗气力，气力空→超比例耗体力→体力空→减生命 |
| 跨模组兼容 | 自动检测其他模组的能量属性（魔力/修为等），转换为气力 |

单位面板中气力显示为：`气力：100/300（Lv3）`

**能级公式**：`能级 = 气力 × 身体素质系数 × 配置倍率`
身体素质系数 = `1 + (伤害 + 生命/10 + 速度/2) / 100`，范围1.0~2.5

### 2.4 知识系统

知识是超能者后天学习的技能/理论，通过潜能点解锁。点击单位面板"知识"行打开独立窗口。

**知识窗口结构**：
1. **顶部**：系别切换（5个按钮）+ 潜能点显示
2. **左侧**：知识树列表（按阶位分组，点击节点查看详情）
3. **右侧**：知识详情（描述/解锁条件/奖励）+ 解锁按钮
4. **3D图谱**：4D超立方体可视化，已解锁节点发光，可拖拽旋转

**知识阶位**：
- 基础（灰）→ 进阶（绿）→ 高端（蓝）→ 尖端（紫）→ 终极（金）

**解锁条件**：
- 消耗潜能点（基础2点，进阶4点，高端6点...）
- 前置知识已解锁
- 跨系兼修消耗×3（智力≥20时×2）

**知识协同**：同时学习特定知识组合可激活协同效果，获得额外加成。

### 2.5 装备背包系统

点击单位面板"背包"行打开独立窗口。单位有独立的装备背包，支持9级原著品质：

| 品质 | 颜色 | 说明 |
|---|---|---|
| 普通 | 灰 | 基础装备 |
| 优秀 | 绿 | 小幅加成 |
| 精良 | 蓝 | 中等加成 |
| 稀有 | 淡紫 | 较好加成 |
| 史诗 | 紫 | 强力加成 |
| 传说 | 粉 | 顶级常规装备 |
| 神器 | 橙 | 使徒兵器级 |
| 神话 | 银橙 | 宇宙宝物级 |
| 超神 | 金 | 最高品质 |

**装备获取**：
- 击杀掉落（品质随机）
- 机械系制造（学会图纸后）
- 装备融合（多件合成更强装备）

**装备词条**：每件装备有随机词条（伤害/生命/攻速/气力等）
**精炼系统**：消耗材料提升装备气力加成
**耐久系统**：装备有耐久度，战斗中消耗，耐久归零装备损坏

### 2.6 机械造兵系统

机械系专属玩法，点击单位面板"制造"行打开独立窗口。

**造兵流程**：
1. 选择配方（9种，从游骑兵到使徒兵器）
2. 确认材料消耗（金属/宝石/精金/金等）
3. 所在城市有足够资源即可制造
4. 制造出的机械单位归主人控制

**造兵收益**：机械单位击杀敌人时，主人获得经验分成。

### 2.7 降临者系统

降临者是"有面板的玩家型单位"（玩家身份），与星海人（土著）的区别：

| 项目 | 降临者 | 星海人 |
|---|---|---|
| 成长方式 | 经验值→升级→进阶任务→转职 | 阶位修炼（自动晋升） |
| 身份标识 | 单位面板显示"降临者" | 普通超能者 |
| 知识融合 | 可随机融合知识配方 | 不可 |

**进阶任务**：降临者达到等级上限后，需要完成进阶任务才能转职：
- 任务级别随机（D/C/B/A/S），级别越高奖励越好
- 任务内容：击杀对应阶位的对手
- 完成后自动转职+获得经验/气力/潜能点奖励

### 2.8 圣所系统

六大圣所是跨存档的知识传承系统，点击神权栏"圣所"按钮打开窗口：

| 圣所 | 知识方向 |
|---|---|
| 第一圣所 | 机械系 |
| 第二圣所 | 武道系 |
| 第三圣所 | 异能系 |
| 第四圣所 | 魔法系 |
| 第五圣所 | 念力系 |
| 第六圣所 | 信息态技术 |

**圣所权限**：每个单位有独立的圣所权限等级（自定义属性），通过神性蜕变获得。

**复苏机制**：
- S阶以上单位死亡后，可通过圣所复苏
- 复苏消耗钥匙碎片
- 复苏后属性削弱（信息丢失，每次+10%，最多50%）
- 信息丢失过多会降阶，降到A级以下无法复苏
- 超神级（X阶）不靠圣所，信息态自动重生

### 2.9 神性蜕变

神性蜕变是高阶超能者的进阶系统，双路线：

| 路线 | 说明 |
|---|---|
| 职业蜕变 | 提升职业能力，最多10层 |
| 种族蜕变 | 提升种族能力，最多10层 |

**触发条件**：气力Lv21 + 能级78000欧纳

**收益**：每层提升属性，获得圣所权限碎片

### 2.10 超神突破

SS阶巅峰超能者可尝试突破超神级（X阶）。

**三条件**（原著ch1396）：
1. 稳定生命形态（持有宇宙宝物）
2. 四个非同系助手（都开启神性蜕变）
3. 超神遗力催化剂

**突破风险**：
- 成功率受多种因素影响
- 失败会死亡，化为超神遗力（无法圣所复苏）
- 成功后成为超神级，信息态永生

## 三、常见问题

### Q: 为什么单位面板什么都没有？
A: 普通人（未觉醒）没有超神机械师的信息。先用神权召唤超能者，或等待单位自然觉醒。

### Q: 知识窗口打开是空白？
A: 知识窗口只显示当前选中系别的知识。先在顶部系别切换按钮选择一个系。

### Q: 怎么获得潜能点？
A: 升级/进阶任务/战斗/神性蜕变都会获得潜能点。

### Q: 装备怎么穿？
A: 背包窗口中点击物品即可装备/卸下。

### Q: 降临者和星海人哪个强？
A: 没有绝对强弱。降临者前期升级快，星海人后期阶位修炼稳定。高阶位后两者趋同。

### Q: 怎么制造机械单位？
A: 机械系单位点击面板"制造"行打开制造窗口，选择配方，需要所在城市有足够资源。

### Q: 和其他模组冲突吗？
A: 气力系统已做跨模组兼容，会自动检测其他模组的能量属性（魔力/修为等）并转换为气力。自定义属性显示在单位面板概览区域。

## 四、配置项

模组有31个配置项，在NML配置界面中可调整：

| 分类 | 说明 |
|---|---|
| General | 通用设置（调试模式/日志级别） |
| Awakening | 觉醒相关（自动觉醒概率/天赋分布） |
| Qi | 气力相关（修炼速度/消耗比例/能级倍率） |
| Promotion | 晋升相关（自动晋升上限/晋升间隔） |
| Sanctuary | 圣所相关（复苏消耗/权限获取） |
| Mech | 机械相关（造兵冷却/材料倍率） |
| Refinement | 提炼法相关（气力获取倍率） |
| Performance | 性能相关（tick间隔/最大单位数） |

## 五、与原版的兼容性

- 不修改原版单位/物品/特质，只添加新内容
- 原版装备系统与模组装备背包共存
- 原版特质/基因/心智Tab不受影响
- 知识和背包使用独立窗口，不占用单位面板Tab
- 存档兼容：禁用模组后，超神机械师的自定义数据会被忽略，原版数据保留
